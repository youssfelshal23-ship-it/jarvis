JARVIS ANDROID - PHASE 1
========================

ماذا تحتوي هذه النسخة؟
- واجهة JARVIS زرقاء مستوحاة من أجواء Iron Man.
- شاشة Reactor متحركة.
- محادثة نصية تجريبية.
- تجربة تحويل النص إلى صوت إنجليزي بريطاني إذا كان الصوت متاحاً في الهاتف.
- تجربة التعرف على الكلام من خلال متصفح يدعم Web Speech API.
- ملفات PWA قابلة للتثبيت على الشاشة الرئيسية بعد رفعها على استضافة HTTPS.

مهم:
هذه مرحلة الواجهة وتجربة الميكروفون فقط. الردود ليست ذكاءً اصطناعياً حقيقياً بعد.
لا يوجد مفتاح API داخل ملفات الواجهة. في المرحلة الثانية سنضيف خادماً آمناً لربط نموذج الذكاء الاصطناعي والصوت دون كشف المفاتيح.

التشغيل على الموبايل:
1) فك ضغط الملف.
2) ارفع محتويات المجلد إلى مستودع GitHub جديد (وليس ملف ZIP نفسه).
3) من المستودع: Settings > Pages.
4) اختر Deploy from a branch ثم main و /root ثم Save.
5) انتظر رابط الموقع الذي ينتهي بـ github.io.
6) افتح الرابط في Google Chrome على Android.
7) اسمح باستخدام الميكروفون.
8) من قائمة Chrome اختر Add to Home screen أو Install app.

اختبار سريع:
- جرّب الضغط على زر الميكروفون وقل: "أهلاً جارفيس". (التعرف على الكلام مضبوط افتراضياً على العربية المصرية؛ غيّر ar-EG إلى en-GB داخل app.js للتجربة بالإنجليزية.)
- جرّب كتابة أمر في صندوق المحادثة.
- زر الميكروفون يعمل عند دعم المتصفح للتعرف على الكلام، وقد يتطلب اتصال إنترنت.

ملاحظة الصوت:
المتصفح يستخدم الأصوات المتاحة على جهازك. هذا ليس صوت Paul Bettany الأصلي ولا نسخة مطابقة منه.
